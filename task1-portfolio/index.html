MERN Stack MongoDB JWT Auth Excel Export

Architecture & Core Capabilities

Kharcha Tracker is a full-featured personal and business expense tracking application built on the MERN stack with modern Vite tooling and Tailwind CSS styling.

  • Authentication: Secure user sign up & log in using JSON Web Tokens (JWT) and Bcrypt password hashing.
  • API Interceptors: Axios interceptors automatically inject auth bearer tokens and handle 401 session expirations.
  • Interactive Analytics: Dynamic financial charts categorizing spend vs. income streams.
  • Reporting: One-click automated XLSX / CSV transaction history export.

Architecture & Core Capabilities

ShopHub is a multi-role e-commerce web application engineered with robust Object-Relational Mapping (Eloquent ORM) and normalized relational database schemas.
